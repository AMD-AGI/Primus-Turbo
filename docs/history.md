# Primus-Turbo History

Every What's New entry, newest first. The [README](../README.md#-whats-new) shows the latest eight; each new entry goes both there and here. An entry is a release, a new feature, or a capability a new model needs; optimizations, wider shape or dtype coverage, fixes and dependency bumps are left to the release notes. A release series (v0.6.x) has one entry, at its latest release. Each release links to its GitHub release page, which lists every merged pull request.

## 2026

- **[2026/11/02]** 🔥 **DeepEP on MI455X (gfx1250)** — FlyDSL intranode dispatch / combine: the V1 kernels ported to gfx1250 and a new TDM-based V2 backend (`flydsl_v2`, the default on gfx1250). EP4 training on 4× MI455X is 1.08–1.10× faster than Megatron's alltoall dispatcher on a DeepSeek-V3 proxy and 1.04–1.07× on GPT-OSS 20B, with 12–16 GB less memory per GPU ([#583](https://github.com/AMD-AGI/Primus-Turbo/pull/583), [guide](../primus_turbo/pytorch/deep_ep/README.md), [design](./flydsl_deepep_mi455.md)).
- **[2026/10/28]** 🔥 **MegaMoE on MI455X (gfx1250)** — BF16 fused MegaMoE forward and backward on gfx1250, including the staged op with per-expert biases for GPT-OSS shapes; validated on 4× MI455X (EP4) ([#582](https://github.com/AMD-AGI/Primus-Turbo/pull/582), [overview](./mega_moe.md)).
- **[2026/10/19–10/27]** 🔥 **Attention on MI455X (gfx1250)** — FlyDSL MLA attention for DeepSeek-V3 (qk 192 / v 128) ([#567](https://github.com/AMD-AGI/Primus-Turbo/pull/567)); FlyDSL flash attention for head dim 128 (Llama-3.1-8B) and sparse-MLA for DeepSeek-V4 ([#580](https://github.com/AMD-AGI/Primus-Turbo/pull/580)).
- **[2026/10/21]** 🔥 **Release [v0.6.1](https://github.com/AMD-AGI/Primus-Turbo/releases/tag/v0.6.1)** ([v0.6.0](https://github.com/AMD-AGI/Primus-Turbo/releases/tag/v0.6.0) plus a test fix) — the first gfx1250 BF16 grouped GEMM ([#508](https://github.com/AMD-AGI/Primus-Turbo/pull/508)), the `mlp_fp4` and `rmsnorm_residual_fp4` fused ops ([#509](https://github.com/AMD-AGI/Primus-Turbo/pull/509)), and MiniMax-M3's SwiGLU-OAI in MegaMoE ([#538](https://github.com/AMD-AGI/Primus-Turbo/pull/538)) ([changes since v0.5.0](https://github.com/AMD-AGI/Primus-Turbo/compare/v0.5.0...v0.6.1)).
- **[2026/09/16]** 🔥 **Release [v0.5.0](https://github.com/AMD-AGI/Primus-Turbo/releases/tag/v0.5.0)** — MegaMoE / GroupedMLP MXFP8 maturity, FlyDSL grouped GEMM BF16, and operator auto-tune on MI355X ([changes since v0.4.0](https://github.com/AMD-AGI/Primus-Turbo/compare/v0.4.0...v0.5.0)).
- **[2026/08/25–09/14]** 🔥 **Fused GroupedMLP (FP8 / MXFP8)** — expert MLP with SwiGLU folded into grouped GEMM; pad-aware paths for GPT-OSS-20B-style MoE ([#476](https://github.com/AMD-AGI/Primus-Turbo/pull/476), [#488](https://github.com/AMD-AGI/Primus-Turbo/pull/488), [#503](https://github.com/AMD-AGI/Primus-Turbo/pull/503)).
- **[2026/08/18]** 🔥 **MegaMoE (MXFP8)** — fused forward and backward in the MXFP8 MegaMoE path: dispatch+FC1 and FC2+combine with intra-node EP ([#456](https://github.com/AMD-AGI/Primus-Turbo/pull/456)).
- **[2026/07/30]** 🔥 **Release [v0.4.0](https://github.com/AMD-AGI/Primus-Turbo/releases/tag/v0.4.0)** — grouped GEMM autotune, MXFP4 correctness, and MegaMoE stability fixes on gfx950.
- **[2026/07/15]** 🔥 **MegaMoE (BF16)** — FlyDSL fused MoE layer with comm–compute overlap inside the grouped GEMMs ([overview](./mega_moe.md)) ([#412](https://github.com/AMD-AGI/Primus-Turbo/pull/412)).
- **[2026/07]** 🔥 **MXFP4 GEMM & grouped GEMM** — FlyDSL and hipBLASLt stacks for dense and expert GEMMs in low-precision training ([#424](https://github.com/AMD-AGI/Primus-Turbo/pull/424), [#483](https://github.com/AMD-AGI/Primus-Turbo/pull/483)).
- **[2026/06/12]** **Release [v0.3.1](https://github.com/AMD-AGI/Primus-Turbo/releases/tag/v0.3.1)** (after [v0.3.0](https://github.com/AMD-AGI/Primus-Turbo/releases/tag/v0.3.0) on 2026/04/13) — backend management and auto-tune infrastructure ([#167](https://github.com/AMD-AGI/Primus-Turbo/pull/167)), MXFP4 GEMM and MXFP8 / MXFP4 quantization ([#179](https://github.com/AMD-AGI/Primus-Turbo/pull/179), [#195](https://github.com/AMD-AGI/Primus-Turbo/pull/195)), sink attention with sliding window ([#208](https://github.com/AMD-AGI/Primus-Turbo/pull/208), [#262](https://github.com/AMD-AGI/Primus-Turbo/pull/262)), attention `sbhd` / `bhsd` layouts and AITER varlen attention ([#275](https://github.com/AMD-AGI/Primus-Turbo/pull/275), [#304](https://github.com/AMD-AGI/Primus-Turbo/pull/304), [#332](https://github.com/AMD-AGI/Primus-Turbo/pull/332)), and JAX single-node DeepEP dispatch / combine ([#162](https://github.com/AMD-AGI/Primus-Turbo/pull/162)).

The separate rocSHMEM backend integration is tracked in [#409](https://github.com/AMD-AGI/Primus-Turbo/pull/409) ([guide](../primus_turbo/pytorch/deep_ep/README.md)).
