# Primus-Turbo History

Every What's New entry, newest first. The [README](../README.md#-whats-new) shows the latest eight; each new entry goes both there and here. Each release links to its GitHub release page, which lists every merged pull request.

## 2026

- **[2026/11/02]** 🔥 **DeepEP on MI455X (gfx1250)** — FlyDSL intranode dispatch / combine: the V1 kernels ported to gfx1250 and a new TDM-based V2 backend (`flydsl_v2`, the default on gfx1250). EP4 training on 4× MI455X is 1.08–1.10× faster than Megatron's alltoall dispatcher on a DeepSeek-V3 proxy and 1.04–1.07× on GPT-OSS 20B, with 12–16 GB less memory per GPU ([#583](https://github.com/AMD-AGI/Primus-Turbo/pull/583), [guide](../primus_turbo/pytorch/deep_ep/README.md), [design](./flydsl_deepep_mi455.md)).
- **[2026/10/28]** 🔥 **MegaMoE on MI455X (gfx1250)** — BF16 fused MegaMoE forward and backward on gfx1250, including the staged op with per-expert biases for GPT-OSS shapes; validated on 4× MI455X (EP4) ([#582](https://github.com/AMD-AGI/Primus-Turbo/pull/582), [overview](./mega_moe.md)).
- **[2026/10/19–10/27]** 🔥 **Attention on MI455X (gfx1250)** — FlyDSL MLA attention for DeepSeek-V3 (qk 192 / v 128) and a tuned BF16 grouped GEMM ([#567](https://github.com/AMD-AGI/Primus-Turbo/pull/567)); FlyDSL flash attention for head dim 128 (Llama-3.1-8B) and sparse-MLA for DeepSeek-V4 ([#580](https://github.com/AMD-AGI/Primus-Turbo/pull/580)).
- **[2026/10/21]** **FlyDSL GEMM correctness on gfx950** — fix three races in the FlyDSL dense FP8 / MXFP8 / MXFP4 GEMMs that silently returned wrong results; the autotune no longer picks a config that is not reproducible ([#570](https://github.com/AMD-AGI/Primus-Turbo/pull/570)).
- **[2026/10/21]** 🔥 **Release [v0.6.1](https://github.com/AMD-AGI/Primus-Turbo/releases/tag/v0.6.1)** (patch over [v0.6.0](https://github.com/AMD-AGI/Primus-Turbo/releases/tag/v0.6.0)) — MegaMoE ownership and MXFP8 combine fixes, MXFP4 gather fusion into quantization, tensorwise FP8 from the TURBO permute, head_dim-128 fused QK RMSNorm + RoPE, DeepEP cheap-fence default, and FlyDSL attention / GEMM correctness on gfx950 ([changes since v0.5.0](https://github.com/AMD-AGI/Primus-Turbo/compare/v0.5.0...v0.6.1)).
- **[2026/10/21]** 🔥 **Release [v0.6.0](https://github.com/AMD-AGI/Primus-Turbo/releases/tag/v0.6.0)** — MXFP8 / MXFP4 dense and grouped GEMM speedups on gfx950 ([#505](https://github.com/AMD-AGI/Primus-Turbo/pull/505), [#514](https://github.com/AMD-AGI/Primus-Turbo/pull/514), [#523](https://github.com/AMD-AGI/Primus-Turbo/pull/523)), `mlp_fp4` and `rmsnorm_residual_fp4` fusions ([#509](https://github.com/AMD-AGI/Primus-Turbo/pull/509)), FlyDSL RoPE / RMSNorm fusions for Llama-3.1-8B and GPT-OSS ([#519](https://github.com/AMD-AGI/Primus-Turbo/pull/519), [#537](https://github.com/AMD-AGI/Primus-Turbo/pull/537)), MiniMax-M3 SwiGLU-OAI in MegaMoE ([#538](https://github.com/AMD-AGI/Primus-Turbo/pull/538)), HIP / Triton `moe_permute` backends ([#455](https://github.com/AMD-AGI/Primus-Turbo/pull/455)), and the first gfx1250 BF16 grouped GEMM ([#508](https://github.com/AMD-AGI/Primus-Turbo/pull/508)).
- **[2026/10/19–10/21]** 🔥 **MegaMoE: dispatch-sized buffers & GPT-OSS** — size BF16 / MXFP8 MegaMoE memory to the rows dispatched to each rank ([#566](https://github.com/AMD-AGI/Primus-Turbo/pull/566), [#568](https://github.com/AMD-AGI/Primus-Turbo/pull/568)); support GPT-OSS shapes (H/I=2880) and per-expert biases ([#571](https://github.com/AMD-AGI/Primus-Turbo/pull/571)) ([overview](./mega_moe.md)).
- **[2026/10/19]** 🔥 **FlyDSL 0.3.4.1 / AITER v0.1.24.post1** — port kernels to FlyDSL 0.3 and bump the pinned AITER release ([#544](https://github.com/AMD-AGI/Primus-Turbo/pull/544)).
- **[2026/09/16]** 🔥 **Release [v0.5.0](https://github.com/AMD-AGI/Primus-Turbo/releases/tag/v0.5.0)** — MegaMoE / GroupedMLP MXFP8 maturity, FlyDSL grouped GEMM BF16, and operator auto-tune on MI355X ([changes since v0.4.0](https://github.com/AMD-AGI/Primus-Turbo/compare/v0.4.0...v0.5.0)).
- **[2026/08/25–09/14]** 🔥 **Fused GroupedMLP (FP8 / MXFP8)** — expert MLP with SwiGLU folded into grouped GEMM; pad-aware paths for GPT-OSS-20B-style MoE ([#476](https://github.com/AMD-AGI/Primus-Turbo/pull/476), [#488](https://github.com/AMD-AGI/Primus-Turbo/pull/488), [#503](https://github.com/AMD-AGI/Primus-Turbo/pull/503)).

- **[2026/07]** 🔥 **MXFP4 GEMM & grouped GEMM** — FlyDSL and hipBLASLt stacks for dense and expert GEMMs in low-precision training ([#424](https://github.com/AMD-AGI/Primus-Turbo/pull/424), [#483](https://github.com/AMD-AGI/Primus-Turbo/pull/483)).
