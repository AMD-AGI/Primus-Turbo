# e2e A/B：ASM 反向在真实训练里值多少

配置 `repro_l8b_turbo_conv.yaml`（llama-3.1-8B，b=4 s=8192，单卡，converter 打开，
compile 关闭，hipBLASLt 走修正路径），20 步，唯一差别是 `PRIMUS_TURBO_ATTN_DISABLE_ASM_BWD`。

## 事前预测（在看到对照臂之前写下）

由已测量的 op 级数字推导：

```
单步时长     = 32768 tokens / 1858 tps = 17.64 s
attention    = 32 层 × 11.726 ms = 375 ms = 单步的 2.13%
ASM 反向省下 = 32 × (17.686 − 10.160) = 241 ms = 单步的 1.37%
预测 ab-off ≈ 1858 × (1 − 0.0137) ≈ 1833 tps
```

稳态离散实测 0.43%，所以 1.37% 的差异约为噪声的 3 倍，**应当可测**。
若实测显著偏离此值，说明"attention 占比"这个模型有问题，而不是优化有问题。

## 背景：为什么差异这么小

这不是优化无效，是**测量对象占比太小**。单步 17.64 秒里 attention 只有 375 ms。
step 被 GEMM 主导，而 GEMM 目前是 hipBLASLt 68.7 TF/s，距 Triton 的 897 还有 13×。
详见 `BLAS-FINDING.md`。
