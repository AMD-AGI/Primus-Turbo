## 结论：相对提升复现

**本机同机同形状实测**：出厂 **55.785 ms** → 冠军 **19.285 ms** = **2.893×**
B0 上同一比值：28.121 / 10.235 = **2.748×**

相对提升不仅复现，本机还略高（限频下出厂实现受损更重）。该比值只依赖今天本机的两个实测值，
不经过任何跨机换算。

数值路径逐位一致：本机冠军 SQNR `53.6196775297861`，B0 `53.61967753535012` —— 吻合到 9 位有效数字。

## 三个新发现

### 1. `--impl turbo` 也已被 ASM 前向接管（README §7 的问题比记载的更广）

本机 `--impl turbo` 前向 **1.567 ms**，是 ASM 的速度，不是 Triton 前向（B0 上 2.7 → 本机应约 5.2）。
`asm` / `turbo` / `fused` 三者相差 0.4%，是噪声底。
**当前 HEAD 上没有任何一个 impl 能测到纯 Triton 前向**，ASM 的 A/B 无法进行。
这使 HANDOFF §11 第 5 项（补 harness 的 ASM 开关）成为 T2 的前置条件，而非并列项。

### 2. 单卡上 HIP 初始化没有 58–172 秒地板 —— README §6 的对照实验已完成

冠军一次测量 `wall_s` 在 B0 上是 **354 s**，本机 **20.3 s**（同为冷 cache 首跑）。
README §6 的三个假设都已被排除，剩下的解释是内核侧 KFD 上下文创建被序列化 —— 本机单卡结果
**支持该解释**：不是 ROCm 版本、不是镜像、不是冷启动，而是多卡并发。

副作用：本机一次测量约 20 秒而非 6–14 分钟，所以每行都能做 n≥3 重复。
B0 上冠军 n=1（`final_champion.sh` 计划 3 对，ledger 只有 1 对），本机 n=4 离散 0.57%。
