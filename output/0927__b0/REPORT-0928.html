关键发现

  • 投机 softmax 在真实数据上是负收益 判死 h45：真实 q/k/v 的 score 标准差为 21–53（randn 为 1），13–25% 的 tile 步会触发重算（randn 为 0%）。r6 在训练中每层是 ASM 的 1.45–1.72×，并且随训练步变慢（fwd 50.2 → 55.3 → 59.2 ms/步）。r13ns 与 r13 输出逐位相同，randn 上时间比为 1.048，真实数据分块下为 0.846–0.919，训练工作点下为 0.774–0.880。e2e 中 fwd 从 53–60 降到 48–49 ms/步，且不再随步数漂移。
  • 训练中 fwd 差距的分解：0.84（2350 MHz、randn 下 fly 更快）× 1.43（时钟）× 1.32（数据）≈ 1.58。FlyDSL fwd 从 2350 MHz 降到 1350 MHz 时慢 1.25×，而 ASM 为 0.97×，基本不受时钟影响。
  • 小 grid 路线有效：m16x8 gate（r9 fast +27.5%）→ m32x2 2-wave（r11 +8.4%）→ 4-wave + d 切分（r13 +5.6%），fast 形状从 97.4 TF/s（r6）升到 162.3 TF/s（r13，ASM 的 105.5%）。prod 不受影响。
  • JIT 缓存陷阱 h46：FlyDSL 0.3.4.1 的 _jit_function_cache_key 不包含模块级常量。只改 SPEC_STALE_MAX 后，/tmp/flycache 仍然返回旧二进制，逐字节相同的 A/A 副本读数差了 6.6%。
  • 已关闭的方向：L12 4-wave × 2 WG/CU（分块下 −0.4%，proxy −7%）；L21 bnegg（+0.3%，null）；L22/L23/L24/L4/L5（lab2 全部 null 或 loss）；在投机代码体上加 nodelay（−1.65%）。
  • r14–r18 平台期：在 randn 分块尺子上冠军约为 ASM 的 0.97，各轮提升都在 ±1% 以内。h47 已把目标改为减少发射量和时钟敏感度（v_nop、SALU、barrier）。
